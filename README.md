# エンドラを虐めようの会(別名ハエたたき)
エンドラを圧倒的武力で虐めることができます。
## メインMod
### clickmanaita
いわずと知れたアイテム複製Mod。
### Tacz
銃Mod。モブを殺すためにあります。
### slashblade-resharped
刀Mod。これもモブを殺すためです。
また、着地時に振ることで水バケツの代わりになります。
## 進行チャート（例）
* **1.** まな板をつくり、`鉄・銅・金・ラピス・ダイヤ・火薬`を手に入れます
* **2.** ネザーに行き、`エンダーパール・ブレイズロッド`を手に入れます
* **3.** `エンダーアイ`をつくり、エンドポータルを発見します
* **4.** エンダードラゴンを撃ち抜き、エンドポータルに入ります!!
